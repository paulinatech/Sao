| **Colores** | Color principal | `#C41E22` | Sello red — used for badges, hover accents, and highlights |

| **Tipografía** | Fuente para textos | `Inter` | Neutral, screen-optimised body font |
| **Tipografía** | Peso para textos | `400` / Regular | Clean and readable, no decoration |
| **Botones** | Estilo de botón | Outlined / Borde | Core to the editorial visual system |
| **Botones** | Bordes redondeados | `0px` | Sharp corners everywhere — no pill or rounded shapes |
